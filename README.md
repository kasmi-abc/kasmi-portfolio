# Kasmi Portfolio

Personal portfolio of Kasmi Haithem, Full Stack Developer. Trilingual showcase (EN/FR/AR) of web applications, e-commerce platforms, SaaS systems and landing pages, with project case studies and contact form.

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Framer Motion · Lucide Icons

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000
